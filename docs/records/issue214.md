이 기록은 반복 계약 검증과 발행 지연 방지의 완료 조건을 증거에 연결합니다. 공개 libcamera 시험과 사내 HAL 검증은 별개이며, 사내 검증은 수행하지 않습니다.

기준 생성기는 `2793c94d7307813ce4effbb24c59eee26999e0e3`입니다. 착수 시 작업 트리는 깨끗했고 최신 origin/main과 같았습니다. 진행 중인 PR #217은 별도 작업으로 보존합니다. 이슈 본문은 2026-10-31에 확인했으며 댓글은 없었습니다.

성능 비교의 고정 기준은 생성기 `ea5fa4c1b4eb2748d373cc911c3d4c67e87a93a1`, libcamera `293d751a814e0d4c34e85ad457ccd9d5eefd1a61`, SDD `85b4cd8d6fd9e1778eac3f20cbd0df0e6b8b7cf3`입니다. 원본 영수증과 판정을 새 실행 결과로 바꾸지 않습니다.

## 실행별 모델 선택

생성·번역은 독립 Claude Code CLI `claude-haiku-5-5`와 `--effort high --setting-sources project,local`을 사용합니다. 독립 근거 검토는 별도 Codex CLI `gpt-6.1-terra`와 `-c model_reasoning_effort="high"`를 사용합니다. 공개 기본 프로필이나 전역 설정은 바꾸지 않습니다. 설치 확인 결과는 Claude Code `2.1.284`, Codex CLI `0.166.0-alpha.5.1`이며, 설치 확인은 모델 호출 성공을 뜻하지 않습니다.

토큰·시간·호출 예산을 추가로 설정하지 않습니다. 장시간 실행 전에 대상 문서·질문과 신규·재검증·이월 사유를 확정하고 기존 impact·design_reuse·checkpoint·generation_run으로 기록합니다. #215 전체 시각화 보완과 #163 전체 독자 평가는 이 작업 범위에 포함하지 않습니다.

이 문서는 검증 결과를 연결하는 표 중심 기록이므로 항목별 그림을 생략합니다. 변경하는 공개 문서의 독립 항목은 별도 시각화 검토 대상으로 남습니다.

다음 절차는 [사이트 구성과 검증](../concepts/site.md)을 따릅니다.
