공개 문서의 분석 기준은 `be7e83e91348250c015aad6d6f59f1468555bae8`입니다. 공식 upstream과 공개 미러는 `c19d05128f3ae1f0ebe63acb4deaca9fbb1dde78`까지 동기화했습니다. 이후 19개 커밋에서 이번 계약 검토에 사용한 네 소스 파일은 바이트가 같습니다. 추가 IPA·장치 변경은 별도 분석 범위입니다. 실제 소스 창·선택 단위·이전 보고서·시도·원본 네이티브 기록은 공개 반영 패키지에 보관합니다.

재실행 절차는 [공개 예제](../../examples/libcamera/validation/contract-uncertainties/README.md)에 있습니다. 실제 모델은 Codex CLI / `gpt-6.1-terra` / high이며 별도 독립 검토를 수행합니다. 이전 체크포인트의 현재 검증은 신규 호출과 구분합니다. 과거 생성자·topic 입력 식별자·페이지 전체 검토 상태를 새 전체 검토로 승격하지 않습니다.

일부 시도에서 저장 경로, 기존 검토 상태 전제, 실행 장부, limitation 설정과 선택자 범위의 로컬 준비·조립 오류가 발생했습니다. 완료된 CLI 응답이 있더라도 그 시도의 전체 성공으로 바꾸지 않으며 실패 원본을 보존합니다. 수정 후에는 표준 체크포인트의 원본 영수증을 검증하고 임시 원고의 선택 단위·보존 답변·순서를 확인한 뒤 교체합니다.

전체 함수 인용을 모든 분기에 강제한 추가 시도는 CLI 사용 한도와 의미 중복 검사에서 중단됐습니다. 최종 질문은 앞선 검사 조건을 전체 함수로 대조하면서 분기별 발췌를 선택할 수 있도록 구성했습니다. 재개 후 실제로 통과한 선택 단위와 표준 재검증 기록을 연결했습니다.

계약 판정과 미판정 목록을 직접 편집하지 않습니다. 실제 원고·영어·현재 근거를 대상으로 정상 `audit-consistency`를 실행합니다. 기존 미판정의 사라짐만이 아니라 새 원문과 검토 이유·소스·남은 항목을 대조합니다. 최종 수치와 Pages·실제 공개 바이트 확인은 이 변경을 반영한 공개 PR과 패키지에 기록합니다.

작성 맥락 없는 파트원·기술 의사결정자 관점의 서브에이전트 재평가는 자동 대리 평가입니다. 실제 사람·임원 평가, 사내 HAL 적용, 실기기 원인·수정 효과와 개발 기간·ROI는 미검증입니다. 세 페이지의 범위 밖 지적이나 일부 인용·화면 확인을 사이트 전체 승인으로 바꾸지 않습니다. 이 짧은 원인 비교는 표와 원본 참조로 충분하여 별도 그림을 생략합니다.
