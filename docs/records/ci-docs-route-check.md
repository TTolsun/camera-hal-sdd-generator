# 문서 전용 CI의 실제 오류 차단 시험

이 기록은 [사전 비교 계획](ci-routing.md#결과를-보기-전에-정한-비교-범위)의 문서 오류 사례를 다룹니다. 첫 시험은 코드 PR #276의 작업 브랜치 `0c846b74a6ee2662f52ddf4953e7d67f846a5c94`를 기준으로 문서 변경만 비교했습니다. 수정본은 코드 PR 병합 후 main을 기준으로 새로 검증합니다. 잘못된 링크가 있는 커밋은 병합하지 않습니다.

첫 커밋 `110debc71de363d9a76843bea5dc5f1a905d3473`은 존재하지 않는 `__missing_ci_validation__.md`를 상대 링크로 사용했습니다. [실제 실패 실행](https://github.com/TTolsun/camera-hal-sdd-generator/actions/runs/41948490913)에서는 scope가 `docs`였고, 네 OS·Python 검사 모두 기존 상대 링크 검사에서만 실패했습니다. 환경별로 642개 시험은 통과했고 의도한 오류 하나가 실패했습니다. 전체 회귀와 첫 병합 통합 단계는 모두 생략됐습니다. 실패 실행·판정 산출물·네 JUnit은 보존했습니다.

| 환경 | 문서 시험 단계 | job 전체 | 결과 |
| --- | ---: | ---: | --- |
| Ubuntu / Python 3.11 | 10초 | 19초 | 의도한 링크 오류 차단 |
| Ubuntu / Python 3.14 | 11초 | 25초 | 의도한 링크 오류 차단 |
| Windows / Python 3.11 | 34초 | 63초 | 의도한 링크 오류 차단 |
| Windows / Python 3.14 | 26초 | 56초 | 의도한 링크 오류 차단 |

workflow 시작부터 완료까지는 85초였습니다. job 합계는 대기 시간을 뜻하지 않으며, 이 값에는 의도적 실패 사례만 포함합니다. 서로 다른 코드 변경의 전체 CI와 동일 입력의 속도 비교라고 해석하지 않습니다.

현재 링크는 실제 [검증 경로 안내](../../ci/README.md#github-검증-경로)로 수정했습니다. 수정 후 네 검사와 최종 병합·main 검증 증거는 [PR #278](https://github.com/TTolsun/camera-hal-sdd-generator/pull/278)의 최신 검사와 병합 기록에서 확인합니다. 경로 판정 흐름은 위 안내의 그림을 사용하고, 이 실행별 시간 비교는 표로 제시합니다.
