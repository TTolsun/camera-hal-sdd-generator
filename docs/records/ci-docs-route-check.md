# 문서 전용 CI의 실제 오류 차단 시험

이 PR은 [사전 비교 계획](ci-routing.md#결과를-보기-전에-정한-비교-범위)의 문서 오류 사례를 실행합니다. 코드 PR #276의 최종 전체 CI를 기다리는 동안 그 작업 브랜치를 기준으로 문서 변경만 비교합니다. 코드 PR 병합 후에는 기준을 main으로 옮기고 링크를 고친 커밋을 새로 검증합니다. 잘못된 링크가 있는 커밋은 병합하지 않습니다.

이 단계의 의도적 오류는 [아직 없는 검증 대상](__missing_ci_validation__.md)입니다. 기대 결과는 scope가 `docs`이고, 네 OS·Python 검사 모두 기존 상대 링크 검사에서 실패하는 것입니다. 전체 회귀와 첫 병합 통합 단계는 선택되지 않아야 합니다. 실패 실행·판정 산출물·JUnit은 그대로 보존하고, 실제 결과를 확인한 뒤 수정합니다.
