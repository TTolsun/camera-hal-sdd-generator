# 문서 수명주기 자동화 검증

**문서 증가·중복·Feature 범위 검사를 생성과 게시 흐름에 연결하고 공개 libcamera로 확인했습니다.** 사내 HAL 적용이나 사람의 의미 승인을 완료한 결과는 아닙니다.

## 생성기 검사

- Windows 회귀 테스트 273개가 통과했습니다. 기존 249개에 문서 수명주기·증분 재시도·게시 차단 관련 24개를 추가했습니다.
- 과도한 본문 증가를 두 번 재시도해도 비교 기준과 완료 커밋이 바뀌지 않는 것을 확인했습니다.
- 새 Feature의 문서 추가, 반복 문단, 표·코드 전체 크기, 누락된 문서·시나리오·심볼, 잘못된 경로·한도를 검사했습니다.
- 폐기 원고가 바뀌면 실패하고, 폐기 확정 후 기존 사이트 파일은 제거하되 원본 원고는 보존하는 것을 확인했습니다.
- 게시 전 검사 실패 시 원격 Git 커밋과 기존 사이트가 유지되는 것을 확인했습니다. `audit-docs`는 문제 발견 시 종료 코드 2를 반환하며 기준선을 바꾸지 않습니다.

코드 검토에서는 생성 전 출력 경로 충돌, 실패 시 기준선 보존, 임시 누락 보완의 기준선 변경 방지, 게시 재개 중 정책 변경 차단을 확인했습니다. 코드·규칙·테스트는 생성기 저장소에 있으며 개인 스킬 설치가 없는 CI에서도 실행합니다.

## 공개 libcamera 검사

공식 upstream의 새 커밋 3개를 확인했습니다. 분석 기준은 `06c3e2d719490aad8ce789fb5d2ad4dfa1459bfb`이며, 주요 변경은 RKISP1에서 카메라별 보정값을 보관하고 configure 시점에 전달하는 수정입니다.

- WSL에서 IPU3·RKISP1·UVC와 GStreamer를 다시 빌드했습니다.
- compile DB의 TU 171개를 재추출하여 클래스 1,005개, 함수 정의 2,852개와 시나리오 6개를 확인했습니다. 파싱 오류와 시나리오 진입점 누락은 각각 0개입니다.
- 인용 위치 5,069개와 파일 336개를 검사했고 잘못된 위치는 없었습니다.
- 새 RKISP1 가이드는 카메라별 보관·입력 오류·스트림 적용의 세 질문과 소스 발췌 7개를 연결합니다. 전체 원고 15편에 대한 문서 수명주기 검사가 통과했습니다.
- 한국어·영어 각각 16페이지를 생성했습니다. 내부 링크 오류는 0개이며 manifest가 검증됐습니다. 동일 입력으로 반복 빌드한 manifest가 일치했습니다.
- 앱 브라우저에서 1440px 데스크톱과 390px 모바일 화면, 새 Feature 검색 결과, 같은 문서의 영어판 전환을 확인했습니다. 모바일 페이지 전체의 가로 넘침은 없었습니다.

보정 화질, 여러 카메라의 동시 촬영, 커널별 동작과 사내 HAL은 별도 검증 대상입니다. 영어판도 사람 검토 전 상태를 유지합니다. 공개 upstream 동기화는 기존 수동 워크플로를 사용하며 정기 예약은 설치하지 않았습니다.

배포된 생성기 커밋·문서 커밋·build ID와 공개 URL 확인 결과는 공개 문서 저장소의 `run.json` 및 해당 PR에 남깁니다.
