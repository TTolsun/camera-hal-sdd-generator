# qcam을 포함하는 추가 비용 시험의 사전 조건

2026-11-05에 빌드·추출 결과를 확인하기 전에 고정한다. 기존 [평가 절차](protocol.md), [원래 부분 비용](cost.json), 자동 독자 시행과 정답 기준은 변경하지 않는다. 이 시험은 같은 실제 qcam 변경을 추가 분석 범위에서 측정하며 기존 운영 프로필의 새 결과로 대체하지 않는다.

변경 전은 `be909e49b7cfcbf8e888b6a17928ae06fd7f9a96`, 변경 후는 `293d751a814e0d4c34e85ad457ccd9d5eefd1a61`이다. 생성기는 `d392d7520b74f2c5a462daaba5c1b72a31f46269`로 고정한다. 기존 공개 분석 빌드는 pipelines=all, IPA 7개(ipu3, mali-c55, rkisp1, rpi/pisp, rpi/vc4, softisp, vimc), cam/gstreamer=enabled, documentation=disabled, test=false, qcam=auto였다. Qt 6이 없어 qcam이 비활성인 사실을 확인했다.

추가 시험은 같은 전체 pipeline·IPA·cam·GStreamer 범위를 유지하고 qcam=enabled로 명시한다. 두 커밋 모두 같은 Qt·Clang·Meson·Python 환경, 같은 세 작업 병렬 빌드를 사용한다. Qt 추가로 자동 선택되는 의존성이 있으면 실제 Meson 옵션·의존성·TU 목록을 함께 보존한다. 사내 HAL·실기기·GPU 렌더링 결과를 측정하는 시험이 아니다.

환경 준비는 Qt 6 개발 패키지 설치이며 18.896초에 완료됐다. 빌드·추출 비용과 별도 항목이다. Qt 6.10.2+dfsg-7, Clang 21.1.8, Meson 1.10.1을 확인했고 실제 패키지 버전·빌드 명령을 원자료에 보존한다. 기존 개인 source/build는 변경하지 않고 별도 Linux 작업 디렉터리에서 수행한다. 공개 libpisp 입력 캐시를 재사용하면 그 경로·Git SHA를 기록하며 컴파일 산출물 재사용과 구분한다.

먼저 부모 커밋을 새로 빌드·추출해 초기 구축 비용을 기록한다. 같은 작업본을 변경 후 커밋으로 이동한 증분 빌드·재추출을 실제 갱신 비용으로 따로 기록한다. 부모·머리 facts를 별도 파일로 보존하고 qcam의 실제 TU·클래스·함수·변경 필드를 확인한다. 이전 시험의 qcam 미추출 facts를 부모 facts로 재명명하지 않는다.

영향 분석은 기존 CLI·impact schema 1과 기본 예제 질문을 유지하며 부모 facts를 전달한다. overview와 component-index의 watch 일치만으로 의미 검토를 완료하지 않는다. 변경된 실제 qcam 근거와 추출·색인 범위를 대조하며 범위 관문이 실패하면 이유·남은 단계를 보존한다. 생성·번역이 필요하면 독립 Codex CLI / gpt-6.1-terra / high의 명시 프로필로 수행하며 검토 프로필은 별도로 유지한다. 실제 호출·재사용·재시도·실패·미시작과 원고/질문/근거의 변경량을 분리한다.

기계 경과 시간은 subprocess 시작부터 종료까지 측정하고 환경 준비·초기 구축·실제 증분·LLM 검토를 합쳐 절감률을 만들지 않는다. CPU·네트워크·모델 서버 대기와 사람 활동을 분리 측정하지 못한 값은 null로 둔다. 사람 검토 시간은 계속 미측정이며 자동 CLI 검토 시간을 넣지 않는다. 비교 가능한 과거 사람 기록이 없어 전체 유지 비용 절감은 판단 불가다.

원자료는 매 실행별 새 경로에 저장하고 실패·timeout에도 단계 장부를 남긴다. 기존 lock·자동 답·사람 CSV·기존 비용은 덮어쓰지 않는다. 이 자료는 실행 조건·측정 정의이므로 별도 제품 동작 그림을 생략한다. 완료 판정은 추가 빌드·추출·영향·필요한 생성/검토/사이트 단계별로 보고하고, 사람 평가나 #253 전체를 완료 처리하지 않는다.
