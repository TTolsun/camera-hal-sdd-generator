# 시행 뒤 확인한 절차 이탈과 재현 한계

세 역할은 독자 시행을 끝낸 뒤 본인 절차를 별도로 감사했다. 이 감사는 새 시험이나 사람 승인으로 세지 않으며 원본 답·시간·기준을 고치지 않는다. 자동 집계는 예비 관측일 뿐 사전 절차를 충족한 비교 실험의 확정 결과가 아니다.

| 역할 | 실제 절차와 사전 정의의 차이 |
| --- | --- |
| E01 | T4·D1·D2의 두 조건 모두 시작 index를 다시 열지 않고 상세 자료를 직접 열었다. 총 6시행의 시작점 이탈이며 B 3건의 단순 기록 누락만으로 표현하지 않는다. |
| E02 | 8시행에서 index를 읽었지만 최초 T2/B 검색은 main 밖 탐색 메뉴도 반환했다. D1/B에서 정지 그림을 읽어 D2/A 전에 B의 관련 내용에 노출됐다. |
| E03 | A는 index 출력과 관련 소스 읽기를 같은 호출에 수행했고 B는 index 검색 뒤 관련 문서를 직접 열었다. 최초 T5/B에서는 main 밖 메뉴를 읽었으며 이후 main으로 제한했다. |

모든 역할이 packet.json 전체를 처음 읽어 모든 과업과 순서를 미리 알았다. started_at은 과업 최초 공개 직전이 아니라 해당 조건의 첫 탐색 호출 직전이다. first_evidence_at은 대체로 첫 읽기 결과를 받은 뒤 측정했으며 실제 파일 열기 순간이 아니다. E03 T5/A는 선언 검색 뒤이자 구현 읽기 전의 시각이다. ended_at은 답을 메모리 객체에 구성하거나 저장하기 직전의 시각이며 최종 파일 기록 완료와 다르다. E01은 8시행 뒤 일괄 저장했고, E03 T5/B는 저장 패치 재시도 때문에 파일 반영이 더 늦었다. 파일 저장·재시도 시간은 경과 시간에 완전히 포함되지 않았다.

조건 간 기억뿐 아니라 앞 과업에서 얻은 함수명·경로·개념을 뒤 과업에 활용했다. 순서 교차로 이를 제거하지 못했다. ‘1차 노출’ 집계는 해당 과업의 조건 자료 순서일 뿐 과업·개념에 대한 독립 최초 노출이 아니다. E02의 shell wall time 합계를 순수 환경 지연으로 해석하지 않는다. 이 위반을 분모에서 삭제하거나 시간·실패를 좋은 새 값으로 대체하지 않는다.

E01 D1/A와 E02 D1/A에 완료 콜백 관측 기준을 다르게 적용했을 가능성이 발견됐다. 원래 grades.json을 보존한 뒤 여섯 D1 답 전체를 같은 고정 기준으로 독립 Terra High에서 다시 대조한다. 새 판정은 d1-consistency.json과 연결하고 변경 이유·검토 비용을 따로 남긴다. 기준을 낮추거나 성공한 답만 재시험하지 않는다.

보조 스크립트 감사에서는 기존 lock·사람 CSV 덮어쓰기, 새 입력과 과거 grades 혼합, 기존 impact 복사 가능성, timeout 미기록, 완료 항목의 무조건 remove, 호출 수 초기화·누적 범위 혼동, checkout SHA 미확인과 잘못된 본문 구분자가 발견됐다. 재사용 도구를 요청받은 작업이 아니므로 새 관리 계층을 확대하지 않고 당시 사본을 실행 불가능한 .py.txt 원자료로 옮겼다. 이 판단은 해당 결함을 수정·검증한 재사용 실행기가 완성됐다는 뜻이 아니다.

현재 평가 입력의 실제 checkout SHA·manifest·과업 패킷 해시는 별도 lock-validation.json으로 재확인한다. 이 확인은 실행 전 모든 조건이 충족됐다는 증거나 사람 효과 증명이 아니다. 새 실제 사람 시험과 완전한 비용 측정은 여전히 남는다.
