# 독자 과업 공백 보완의 진행 기록

[사전 계획](reader-improvement-plan.md)에 따른 후속 작업이다. 원래 24건의 자동 시행·정답표·시간 경계와 사람 결과 양식은 보존한다. **새 자동 과업 재평가는 아직 시작하지 않았고, 사람 참가자는 0명이다.** 따라서 업무 효과와 사람 읽기 부담·검토 시간은 판단할 수 없다. 이 기록의 상태는 진행 중이다.

## 실제 원고 생성과 실패 수정

공개 발행에 사용된 #243의 sections·products·원고·과거 집필 프로필과 CLI 원자료를 해시로 복원했다. 새 문장을 수동으로 작성하여 생성 성공으로 바꾸지 않았다. 보존할 원고의 역사 프로필은 읽기 전용이며 새로운 생성·번역과 별도 검토에는 명시한 Codex CLI / gpt-6.1-terra / high를 사용한다.

잘못된 `python -m sdd.localization_cli` 실행은 종료 코드 0이어도 번역을 수행하지 않았다. 별도 진단에 실제 미실행·카탈로그 동일·호출 0회로 남기고, 문서화된 `python -m sdd.site_localization`으로 실제 번역했다. 최신 소스 단계의 첫 번역도 ROI 용어가 없어 모델 호출 전에 실패했다. 기존 용어를 제거하지 않고 현재 main의 승인된 ROI 정의를 별도 용어집에 추가한 v2 설정을 고정한 뒤 재시도했다. 원래 실패 설정과 장부는 보존한다.

최신 한영 계약의 독립 CLI 검토는 진행 중이다. 이 검토에서 `doQueueRequest()`가 요청을 넣는 `queuedRequests_`를 “대기 목록”으로 표현한 본문과 영어 번역의 불일치를 발견했다. 생성 질문에 정확한 큐 이름과 별도 `waitingRequests_`와의 구분을 추가하고 `queuedRequests_`를 필수 용어로 강화했다. 원래 용어 그룹과 정답 기준은 제거하지 않았다. 새 설정에서의 최초 재생성은 기준 계약의 용어 변경을 명시하지 않아 차단됐고, 다음 실행은 Codex CLI의 Windows 권한 오류로 실패했다. 각각 87.856초·32.588초이며 성공 비용으로 세지 않는다. 계약 강화 이유를 명시한 새 설정과 같은 CLI를 사용해 별도 재시도 중이다. 원고·번역·독립 재검토가 끝나기 전에는 수정 완료로 판정하지 않는다.

각 경과 시간은 해당 subprocess의 시작부터 종료까지다. 단계가 겹치거나 초기 구축·복원·환경 지연이 포함된 경우를 구분하며, 이 표를 단순 합산한 값을 사람 유지 비용이나 소스 변경 한 건의 비용으로 부르지 않는다. CPU·모델 서버 대기·사람 활동을 분해한 값은 측정하지 않아 null이다.

## 비교 가능한 범위와 남은 작업

원래 비교 자료의 source293은 고정한다. 새 발행 준비 소스는 공식 upstream `be7e83e91348250c015aad6d6f59f1468555bae8`이다. T2·D1·D2 정답에 사용하는 공식 문서와 Camera·PipelineHandler·Request의 파일 7개가 두 커밋에서 동일한 것을 SHA-256으로 확인했다. 전체 사이트·환경·조건의 동등성을 뜻하지 않는다. 새 발행에는 별도 이슈의 역할별 진입점·질문 안내와 qcam 포함 추출 범위도 함께 들어간다. 후속 자동 결과를 문장 하나의 인과 효과나 기존 A/B 시험의 새 최초 노출로 해석하지 않는다.

새 upstream의 변경 중 Meson 버전은 기존 영향 분석에서 미매핑으로 검출됐다. 독립 CLI의 범위 검토는 버전 표기만 바뀐 창을 out-of-scope로 분류했다. 이는 자동 범위 판정이며 사람 승인이 아니다. Python 바인딩 변경은 이 빌드의 분석 범위 밖이고 실기기·GPU·Python 실행을 검증하지 않았다. 373개 선택 창의 재대조를 전체 소스의 의미 검토로 확대하지 않는다.

최종 원고·영어 번역·계약 재검토·항목별 그림과 실제 Chrome 화면 검사를 마친 뒤 새 발행 버전과 산출물 해시를 고정해야 한다. 그 뒤 새 컨텍스트의 서브에이전트에 과업 하나·조건 하나만 제공하여 T2·D1·D2를 회귀 점검한다. 읽기 부담과 사람 검토 시간은 자동으로 대신 채우지 않는다. 생성기 PR 병합, 공개 SDD PR 병합, Pages와 실제 산출물 확인도 아직 남았다. #253과 #163은 미완료다.

이 파일은 실행·비교 조건과 비용의 표로 충분하므로 별도 제품 동작 그림을 생략한다. 새 제품 설명의 하드웨어 책임 경계·정지 구현 검토·제출 회차별 완료 비교 그림은 원고와 별도로 검토하며, 이 기록의 표로 제품 그림 검증을 대신하지 않는다.
