## 실패와 복구도 비용에 포함한다

처음 고정한 그림 설정은 원래 공개 manifest의 설정 해시와 달랐으며 두 조건에서 같은 적응 설정을 사용한다고 미리 기록했다. 이 설정의 request-diagnosis 그림 제목 한 개가 원본 원고의 내부 링크 제목과 달라 첫 정상 export는 각각 22.083초·22.457초 뒤 실패했다. 원래 설정과 실패를 보존하고, 두 조건에 공통으로 적용할 별도 복구 설정에서 **원본 원고의 제목만** 복원했다. 노드·간선·질문·근거·원고·독자 루브릭은 변경하지 않았다.

제목 복원 직후에는 영어 카탈로그 소스 해시 검사가 두 조건을 다시 차단했다. 정상 카탈로그 재검증은 각각 10.211초·11.076초였고 신규 모델 호출은 없었다. 검토·영수증·회귀·항목별 점검·역사적 근거의 여섯 before-export 게이트를 유지한 정상 export와 verify-site가 이후 통과했다. 게이트를 제거하거나 실패한 출력을 발행 성공으로 사용하지 않았다. 이 복구는 결과를 본 뒤 분리한 시험 준비 수정이며, 처음부터 동일한 운영 환경을 재현했다는 뜻이 아니다.

로컬 회귀 검사는 처음 171개 통과·2개 생략·15개 실패였고 1,043.344초가 걸렸다. 15개 실패는 깊은 Windows 임시 경로와 Git/MSYS sandbox 권한에서 발생했다. 코드나 검사를 바꾸지 않고 짧은 새 임시 경로와 정상 native 접근에서 **같은 15개만** 재실행해 모두 통과했으며 427.185초가 걸렸다. 최종 구분은 서로 다른 186개 통과·2개 생략이며 처음 실패와 환경 복구 시간을 삭제하지 않는다. 이는 정확한 실험 실행기의 로컬 검사이며 새 운영 CI 실행이라고 부르지 않는다.

## 확인 범위와 남은 한계

두 사이트는 각각 HTML 62페이지·전체 산출물 294개다. 실제 파일을 각 manifest의 SHA-256과 대조했고 내부 링크·앵커 검증을 통과했다. 두 조건의 Mermaid 원문 118개는 모두 같다. 변경 후 산출물을 원래 공개 manifest와 비교하면 98개가 같고 20개가 다르다. **이 통제 자료는 원래 공개 산출물의 정확한 재현이 아니며**, 현재 독자 발행본 대신 공개 main에 배포하지 않는다.

부모와 변경 후의 자동 계약 검토는 각각 불확실한 항목 4건·5건을 남긴 채 통과했다. 이 수는 자동 판정 항목 수이며 같은 claim이 여러 계약에서 나타날 수 있다. 원래 매개변수 수식·누락된 기본 인자 발췌 등의 한계와 모델 변동을 포함하므로 qcam 변경이 품질을 악화시켰다는 인과 증거로 해석하지 않는다. 미해결 항목을 사람 승인으로 바꾸지 않는다.

사람 참가자·사람 검토 활동 시간·읽기 부담은 여전히 미측정이다. 실제 qcam GPU 실행, 물리 카메라·센서·ISP 촬영과 사내 HAL은 검증하지 않았다. [측정·manifest 결과](maintenance-cost-v2/completed-machine-result.json)는 이 통제 단계의 입력·실패·복구·영수증·출력 비교를 연결한다. [원본 패키지](maintenance-cost-v2/package.json)는 파일 2,249개를 보존하며, [별도 복원 검증](maintenance-cost-v2/verification.json)에서 모든 파일과 실제 CLI 영수증 178개의 요청·응답·원시 stdout·인자를 대조했다. 저장 응답을 신규 호출로 실행하거나 사람 승인으로 바꾸지 않았다. 전체 #253이나 사람 유지 비용 검증의 완료를 뜻하지 않는다. 이 기록은 단계 비교 표와 원본 참조로 충분하므로 별도 동작 그림을 생략한다.
