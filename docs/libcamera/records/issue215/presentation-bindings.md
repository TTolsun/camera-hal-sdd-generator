# 항목 표시 상태와 검토 범위 연결

질문의 본문이 같아도 부모 요소나 인용 근거가 숨겨지면 이전 시각화 판정을 재사용하지 못하도록 보완했습니다. 제목·본문·그림·근거 창의 실제 조상, 형제 위치와 텍스트 위치를 지문에 포함합니다. 그림 제목이 질문과 같은 H2 단계여도 실제 그림 소유 항목에 표시 상태를 연결합니다.

HTML5 파서로 문단·목록의 생략된 닫는 태그와 SVG 안의 HTML을 처리합니다. 컨테이너·표·목록·요약 안의 독립 제목도 빠뜨리지 않으며, 원문·로그는 설명 분량에서 분리합니다. 원문·로그 컨테이너가 제목 안에 있으면 명시적으로 실패시켜 근거를 제목 밖으로 옮기게 합니다.

예제의 텍스트 전용 검토 도구는 숨김·인라인 표시·미확인 미디어와 범위 없는 전체 HTML 근거를 추론 전에 거부합니다. 정확한 항목과 한영 대응을 확인하고, 이전 독자 질문 모델은 비교 자료로만 사용합니다. 모델 판정과 사람 승인, 정적 표시 정보와 실제 화면 검증은 구분합니다.

- 연결 검사: `pytest-206`에서 262개 통과. 사이트 교체 실패 시 직전 정상 파일 보존 사례를 포함합니다.
- 별도 실제 코드 검토: Codex CLI `0.166.0-alpha.5.1`, `gpt-6.1-terra`, `model_reasoning_effort="high"`. 마지막 검토 146의 지적은 0건입니다.
- [원본 검토·실패·모의 사례 색인](presentation-native-index.json)과 [원본 묶음](presentation-native.tar.xz)에 실제 검토 122–146의 영수증 25건을 검증해 보존했습니다. 이 수치는 항목 승인이나 그림 보완 수가 아닙니다.
- 이전 독자 모델·비교 문서 입력 기능의 [별도 원본 색인](review-context-native-index.json)과 [원본 묶음](review-context-native.tar.xz)도 유지합니다.

새 엔진으로 최종 한영 조립본을 다시 수집·검토해야 합니다. 이 변경만으로 #215 전체 장부, 그림 보완, 공개 SDD 병합이나 Pages 배포를 완료 처리하지 않습니다. 기존 원고·실행·검토 지문과 사람 승인 상태는 소급 변경하지 않습니다.

## 최신 main과의 통합

다른 세션이 병합한 #267·#279의 `24c851f`를 통합했습니다. 새 기능을 중복 집계하지 않으며, 실제 브라우저가 literal fragment를 먼저 선택하는 규칙을 사이트 검증과 항목·그림 근거 검사에 공통으로 적용했습니다. 실제 IAB의 `#proof%20x`가 `id="proof%20x"`를 선택하는 것을 별도 가상 문서에서 확인했습니다.

첫 CI `41969478964`는 frozen 잠금 파일에 `html5lib`가 없어 실패했습니다. 이 실행은 실패로 남기고 `uv.lock`을 갱신했습니다. 별도 frozen 환경의 Python 3.14.7에서 발행 사전 통합·의존 방향·사이트·번역·항목·주제 연결 검사 313개가 통과했고, 독립 CLI 통합 검토 149의 지적은 0건입니다. [통합 원본 색인](presentation-integration-index.json), [원본 묶음](presentation-integration-native.tar.xz), [테스트 원본](presentation-integration-tests.log.gz)에 실패와 재검증을 구분해 보존합니다. 새 head의 CI 확인은 별도로 수행합니다.
