# 원본을 보존하는 독립 검토 입력 표현

새 IPA 조립 항목 한영 한 쌍의 완전한 JSON 입력은 1,042,277자였습니다. 선택 기능 `--compact-input`은 반복된 값만 공유 참조로 표현해 939,604자로 줄였습니다. 추론 전에 모든 원문·조건·목록 순서·표시 문맥·지문을 복원한 JSON의 정규화 해시가 원본과 같은지 확인했습니다. 원래 입력 파일과 별도 표현·두 해시를 모두 보존하며 객체 키의 원래 삽입 순서나 원본 파일 바이트를 재작성하지 않습니다.

새 기능은 선택적인 독립 검토 입력 표현입니다. 기존 CLI 기본 동작, 생성·번역 모델·focused 응답 JSON, impact.json schema 1과 발행 판정은 바꾸지 않습니다. 공유 표현이 더 크면 일반 JSON으로 돌아가고, 원본에 예약 키가 있거나 참조·자료형이 잘못되면 실패합니다. 공유된 부모 아래에서 한 번만 쓰게 된 자식도 다시 펼쳐 불필요한 간접 참조를 남기지 않습니다.

실제 독립 Codex CLI Terra High 코드 검토 157·158에서 발견한 비효율과 복원기 자료형 문제를 수정했습니다. 검토 159의 findings는 0개이고 관련 회귀 35개가 통과했습니다. 실제 항목 검토 48은 새 한영 조립 항목 두 개를 모두 적절한 그림 있음으로 판정했습니다. 이 한 쌍은 이전 보완 필요 판정 27 이후 연결 그림 39·독립 근거 검토 40·정상 CLI 원고 재개 44·번역 45·링크 검사 46을 거친 범위입니다.

`shared-context-native.tar.xz`와 그 index에는 실제 원본 입력·공유 표현·영수증·코드 검토·좁은 항목 판정과 계획 전용 실행을 함께 보존합니다. 예전 PR #280의 `review-context-native.tar.xz`는 별도 원본이며 변경하지 않았습니다. 이 기록은 전체 SDD, 사람 승인, 실기기, 사내 HAL 또는 공개 배포의 완료가 아닙니다.
