# 본문 뒤 생성·검토 정보의 점검 범위

private20의 실제 66개 한영 페이지에서 `article` 밖이지만 `main` 안에 있는 ‘문서 생성·검토 정보’ H2 66개를 발견했습니다. 검색·확대 대화상자 제목 132개는 읽기 항목이 아닌 제어 영역으로 구분했습니다. 변경된 공통 검사기는 단일 `main` 안의 본문과 이 H2를 함께 수집합니다. 기존 생성 원고는 명시적 `draft=True`의 독립 `article` 경로를 유지합니다.

공개 libcamera 예제의 `require_provenance`는 최종 사이트에 `main`과 직접 생성된 정보 절을 요구합니다. 해당 절과 검토를 함께 지우거나 `main`까지 삭제하는 경우도 통과하지 못합니다. 실패 시 정상 사이트의 모든 파일 바이트를 보존하는 회귀 검사를 추가했습니다. 검사를 실제 발행에 활성화하는 것은 전체 항목의 판정이 끝난 뒤 수행합니다.

독립 Codex CLI Terra High 검토 153은 전체 정보 절 삭제 우회를 발견했고, 155는 `main`까지 삭제한 경우의 우회를 발견했습니다. 둘 다 수정한 실제 검토 156의 findings는 0개입니다. 원본 입력·응답·실행 설정·영수증과 실패 테스트 실행 214를 `main-scope-native.tar.xz`에 보존했습니다. 관련 항목·소스 창·DOM 표시·보존 검사 181개가 통과했습니다(`pytest-215.log`).

최신 검사기의 재수집 결과는 66페이지·870항목이며 추가 정보 절 66개도 아직 미검토입니다. 이전 계획용 목록 804개는 최종 DOM 위치 결합 전 엔진에서 수집되어 지문이 모두 달라졌습니다. 이를 재고정하거나 완료 판정을 물려주지 않습니다. 이 변경은 전체 SDD 검토·공개 배포·사람 승인·실기기·사내 HAL 검증의 완료가 아닙니다.
