Q3는 코드에 도달했지만 변경 후 검증 계획이 불완전했습니다. 원래 여섯 기준으로 완전히 통과한 독립 답변은 0개입니다. ### 실행 비용과 남은 검증

- 기준 및 배포 후 평가, 캡션 생성, 시각화 근거 검토를 합해 CLI 16회 중 15회가 응답을 남겼습니다. 측정된 입력과 출력은 총 1,676,451토큰으로 사전 점검선 160만을 넘었습니다. 모델 실행 전에 실패한 Q1 기준 호출의 토큰은 미측정입니다.
- 독립 읽기 재시도는 57.985초와 52,575토큰을 사용했고, 마지막 독립 소스 검토는 47.328초와 71,669토큰을 사용했습니다. 각 실행이 Q1~Q3를 함께 처리했으므로 이 수치는 세 질문의 공통 비용입니다. 두 실행은 별도 Codex CLI 프로세스에서 `gpt-6.1-terra` / `high`로 수행했습니다. 기준과 배포 후 탐색 방식이 달라 비용 절감률은 계산하지 않았습니다.
- 이번 결과는 공개 libcamera의 자동 평가에 한정합니다. 실제 사람의 독해·생산성, 실기기 재현과 사내 HAL은 측정 범위 밖입니다. 문서 보완은 배포를 확인했습니다. 독립 읽기의 코드 전달과 필수 판단 누락은 후속 범위에 남습니다. [기술 보완 #252](https://github.com/TTolsun/camera-hal-sdd-generator/issues/252)
- [실행 증거](pages-followup.zip)는 질문, 소스 창, Pages manifest, 탐색 로그, 원본 판정, 실행별 사용량을 보존합니다. 소스 근거 검토는 원래 판정 기준과 공식 저장소의 고정 소스 창으로 수행했습니다. 링크에서 받아 독해에 전달한 파일 바이트도 공식 저장소와 대조했습니다.
