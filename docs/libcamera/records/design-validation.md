# libcamera 설계 근거 재검증

2026-09-21에 같은 A/B 커밋으로 설계 내용 보강과 증분 생성을 재검증했습니다. **설계 계약과 구조 반영 검사는 통과했으며, 문서 범위 검토 항목과 사람의 내용 검토가 남아 있어 전체 판정은 부분 통과입니다.** 사내 Camera HAL 검증 결과가 아닙니다.

## 입력과 실행 범위

- A: `0a881d263755d97d912c5fb5302c8de095cd5148`
- B: `279d355ef8f7a4f98bb0a3004c0f788387814506`
- 이전에 전체 빌드와 파싱 오류 0건을 확인한 facts를 재사용했습니다. 이번 실행에서 libcamera를 다시 빌드하거나 구조를 다시 추출하지 않았습니다.
- 각 커밋의 Git 객체에서 설계 주제별 소스 발췌 17개를 추가 수집했습니다. 현재 작업 파일이 아닌 불변 커밋의 본문을 사용했습니다.
- A의 전체 문서 생성 후 실제 Git diff로 영향 분석을 실행하고, A 문서를 복사한 B 출력에 `generate --from-impact`를 적용했습니다.
- Pipeline Handler와 IPA의 설명에는 로컬 Ollama `qwen3.5:4b`, temperature 0을 사용했습니다. 카메라 계약과 LSC 구조 설명은 최종 설정에서 LLM을 호출하지 않습니다.

## 실패 사례에서 보완한 내용

초기 실행에서는 소스 본문을 제공해도 모델이 fence를 Request로 이전한다고 서술하거나 stop의 blocking 호출을 비동기 호출로 설명했습니다. 기존 A 원고를 B의 입력에 넣었을 때는 새로 추가된 Lsc가 없다는 설명도 반복했습니다. 인용이 맞거나 제한적인 구조 검사를 통과했다는 사실만으로 의미가 검증되지 않음을 확인했습니다.

이 실패 원고는 로컬 `design-20260921`, `design-contracts-20260921`, `design-final-20260921`, `design-verified-20260921` 디렉터리에 보존했습니다. 실패한 표본을 지우고 모델을 재호출해 성공 표본만 채택하지 않았습니다. 최종 설정은 다음과 같이 변경했습니다.

- 카메라 계약은 소스를 대조한 설명과 발췌 지문을 연결합니다. 본문이 바뀌면 기존 설명을 표시하지 않고 재검토를 요구합니다.
- LSC 구조는 facts에서 직접 서술합니다. 자유 함수는 HAL 진입점으로 단정하지 않습니다.
- 생성 설명에는 이전 원고를 사실 근거로 넣지 않습니다. 잘못된 상속, 한정 이름, 일부 클래스 부재 주장과 입력에 없는 인용을 검사합니다.
- 별칭을 기반 클래스로 쓰는 경우와 한 문장에 관계가 여러 개 있는 경우의 오탐도 회귀 검사로 보완했습니다.

## 남은 검토 항목

문서 범위 검토 항목은 기존 17개에서 10개로 줄었습니다. 익명 구조체 항목 8개에는 같은 구조체의 A/B 줄 이동이 별도 식별자로 나타난 경우가 포함됩니다. 나머지 두 개는 `algorithms/meson.build`와 주석 위주의 `ipa_context.cpp`입니다. 실제 변경 심볼 10개라는 뜻이 아닙니다. 이 항목을 자동 승인하거나 제외하지 않았으므로 엄격 범위 검사는 보고서를 남기고 종료 코드 2로 중단합니다. 후속 생성은 검토용 산출물을 확인하기 위해 별도로 실행했습니다.

발췌 지문은 연결해 둔 근거의 변경만 확인하며 설명의 참·거짓을 증명하지 않습니다. 발췌 밖 실행 코드, 콜백 스레드, 하드웨어별 종료와 사내 HAL 고유 계약은 별도 검증이 필요합니다. 생성된 원고는 사람 검토 전이며 이번 작업에서 공개 사이트에 배포하지 않았습니다.

설정과 재실행 방법은 [설계 근거 검사](../../concepts/design-evidence.md)를 참고하세요.

## 머지 전 코드 리뷰

2026-09-22 리뷰에서는 같은 커밋에서 질문이나 근거 설정이 바뀐 원고를 사이트가 허용하는 경로와, 패키지·읽기 순서 입력이 이월 지문에서 빠지는 문제를 수정했습니다. 기본 출력 파일명을 사용하는 페이지와 검사 옵션을 제거한 페이지에도 게시 지문 검사를 적용합니다. 수정 후 로컬 회귀 테스트 83개가 통과했고, 보존한 A/B 원고의 사이트 지문·링크·산출물·반복 빌드를 다시 확인했습니다. 위 80개 테스트와 JSON은 최초 A/B 실행 당시의 기록으로 보존합니다.
