# 새 서브에이전트 세 역할의 자동 평가를 확인하세요

2026-11-05 사용자가 다시 요청한 서브에이전트 평가입니다. 새 에이전트 세 개를 신입·타팀·비작성자 관점으로 구성했습니다. **실제 사람은 0명이며 #248·#163과 전체 Goal은 미완료입니다.** 에이전트 역할은 실제 직원의 배경·경험이나 ADHD 이해를 증명하지 않습니다. 역할 에이전트는 상위 작업의 모델을 상속했고, 별도 근거 대조는 독립 Codex CLI / `gpt-6.1-terra` / high로 실행했습니다. 이를 기존 #163 CLI 시험과 같은 모델의 전후 비교로 합산하지 않습니다.

## 먼저 고정한 대상과 과업을 확인하세요

평가 시작 시점의 공개 manifest를 캡처하고, 정확히 일치하는 공개 커밋 [ad19ae6e](https://github.com/TTolsun/libcamera-sdd/tree/ad19ae6e83caa22d60daf736535a98bb29ca4015/docs)를 별도 사본으로 복원했습니다. build_id는 `52d0226eff7ccee8170b3d7c5b4631ec8d9ff00708ab2e5a8b4f14a5bed95b9f`입니다. 과업을 읽기 전에 [프로토콜](protocol.json)과 [과업 카드](participant-inputs/)를 고정했으며 #163의 여섯 과업과 #248의 S·R·X 및 [필수 의미의 바이트 사본](rubrics/protocol.md.txt)은 바꾸지 않았습니다. 원래 위치를 기준으로 한 상대 링크는 [정본 프로토콜](https://github.com/TTolsun/camera-hal-sdd-generator/blob/bc3430b23928a59b492f81256c4b807b4eef60f8/docs/libcamera/records/issue-248/protocol.md)에서 확인합니다. 정답표·작성 이력·이전 평가·다른 역할의 답은 독자 에이전트에 제공하지 않았습니다.

이 공개본은 #249·#250의 별도 개선을 포함하며 분석 소스는 `be7e83e91348250c015aad6d6f59f1468555bae8`입니다. 이전 #248 기준본의 분석 소스 293과 다르므로 전체 차이를 #248의 효과로 귀속하지 않습니다. 새로운 전체 추출·장치 실행·사내 HAL 검증도 수행하지 않았습니다.

## 원답과 판정의 차이를 함께 읽으세요

| 과업 | 최초 독립 CLI 판정 | 원래 최소 의미로 재검토한 판정 |
|---|---:|---:|
| 기본 이해·탐색 | 5/6 부합 | 5/6 부합 |
| S 자기 설명 | 1/3 부합 | 2/3 부합 |
| R 자동 복귀 | 0/3 부합 | 2/3 부합 |
| X 새 조건 | 0/3 부합 | 3/3 부합 |

이는 [자동 판정](summary.json)이며 사람 평가 성공률이 아닙니다. [원답](reader-new/phase1.md), [타팀 원답](reader-other/phase1.md), [비작성자 원답](reader-nonauthor/phase1.md)과 각 2단계 답을 그대로 보존했습니다. 최초 판정은 입력 검사·영상 성공·요청 식별자 등의 특정 표현을 별도 문장으로 반복하지 않았다는 이유로도 미충족을 주었습니다. [S 재검토](assessments/reader-other/S-adjudication/assessment.json)와 [R·X 재검토](assessments/phase2-adjudication/assessment.json)는 사전 최소 의미와 문맥을 대조했으며 원답을 고치거나 기준을 낮추지 않았습니다. 같은 답에 대한 모델 판정의 변동도 한계로 남깁니다.

미충족 세 항목은 유지합니다. 신입 역할의 S에는 버퍼 완료와 요청 전체 완료의 구분이 빠졌습니다. 비작성자 역할은 `completeRequest()`의 CameraManager 스레드 계약을 찾지 못했고, R에서는 중단 전 제보와 ‘성공을 0으로 해석한 것은 실측이 아닌 임시 전제’라는 구분을 복원하지 못했습니다. 이 결과만으로 원인이 문서인지, 과업 표현인지, 모델 판정인지 확정하지 않습니다. 실제 독자의 실패 관측으로 바꾸지 않으며 후속 개선·평가가 남습니다.

## 실제 간격과 읽기 경험의 범위를 구분하세요

[중단 기록](pause-ledger.json)의 실제 간격은 신입 323.922878초, 타팀 330.855992초, 비작성자 360.383231초입니다. 중단 메모를 보존하고 별도 재개 지시 후 index에서 다시 탐색했습니다. 모델은 문맥을 유지하며 무관한 활동이나 사람의 망각을 재현하지 않았습니다. 문서 접근 중단은 에이전트 도구 기록에 기반하며 별도 사람의 화면 관찰이 아닙니다.

여섯 기본 과업의 쉬움·흥미·자연스러움 [AGENT ESTIMATE](experience-estimates.json) 중앙값은 각각 4/5입니다. 정확성과 합산하지 않습니다. 개요에 남은 작성 지시, 책임·지원 범위가 여러 절에 흩어진 점, 미확인 호출 스레드 등의 이유 원문을 함께 보존합니다. 실제 사람의 즐거움·부담·문체 판단을 측정한 값은 아닙니다.

모든 독자 탐색은 로컬 HTML의 본문·링크 텍스트를 사용했습니다. 일부 최초 추출에서는 접힌 발췌·추적 표까지 노출된 편차가 있습니다. 브라우저 가시성·그림 독해의 성공으로 계산하지 않습니다. 비작성자 메모는 Windows 줄바꿈 때문에 최초 보고한 LF 문자열 해시와 실제 바이트 해시가 달랐으며, 실제 원본 바이트를 고치지 않고 두 값을 기록했습니다.
