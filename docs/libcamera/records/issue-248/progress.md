## 관측에 따른 이번 수정

`queue_request`의 접힌 질문 안내에 “세 문단 이내로 작성하세요” 등 집필 지시가 노출됨을 확인했습니다. 공통 생성 경로는 기본적으로 어떤 문장도 삭제하지 않습니다. 확인한 질문 HTML 전체의 SHA-256과 제거할 문장만 `site.coverage_question_edits`로 명시합니다. libcamera 설정의 4개 시나리오·6개 질문에 같은 네 종류의 확인된 집필 지시를 연결했습니다. 기술적 주체·조건·반환값·스레드·전체 소스·절 링크와 원본 Markdown은 보존합니다. 질문이 바뀌거나 누락·중복되면 기존 사이트를 보존하고 실패합니다. 짧아진 분량이나 그림 개수를 성과로 세지 않습니다.

독립 Codex CLI/Terra High 검토에서 일반적인 문구 삭제가 인용·코드·문맥의 요구사항까지 지울 수 있는 경계를 확인하여 명시적 질문 지문 방식으로 바꿨습니다. 반려된 시안과 원본 실행 기록은 최종 통과 기록과 구분하여 보존합니다. 이 검토는 코드·절차의 자동 검토이며 사람의 내용 승인이나 읽기 경험 검증이 아닙니다.

요청 재사용의 행동 요약, 성공/장치 전달/완료 용어, 두 큐 비교, 연동 완료 책임의 상세 연결과 조사 복귀용 상태표는 자동 편집 제안입니다. 실제로 답을 못 찾은 사람 관측은 없으므로 이를 해결된 사람 실패나 부담 감소로 표현하지 않습니다. 기존 설명 소유 문서는 요청 수명·파이프라인 요청·진단 문서로 유지합니다. 해당 제안은 실제 사람 관측 후 원인에 맞춰 개선·재평가할 목록에 남깁니다.

## 실제 평가를 이어가는 방법

`human-results.csv`는 #163의 열을 유지하고 S·R·X, 관측 전후 manifest 캡처, 경로·메모·실제 경험의 기록 열을 추가한 빈 15행입니다. `python -m sdd.reader_study`는 실제로 채점한 사람 기록만 집계하며 에이전트·혼합 build·바뀐 채점표·중복 행·기준 약화를 거절합니다. 실패·미응답·추가 참여자는 원래 분모에 남고 흥미·자연스러움은 정확성과 합산하지 않습니다. 사람 여부·답의 의미·실제 수행 시점은 진행자가 확인해야 합니다.

원본은 비공개로 수집하고 공개 동의 전에는 커밋하지 않습니다. 공개에는 익명 집계만 남깁니다. 다음 입력은 비작성자 3명 이상(신입·타팀 관점 포함)의 실제 수행 결과이며 서브에이전트로 대체할 수 없습니다. 사람 결과가 없거나 기준에 미달하면 Goal과 #248·#163은 미완료입니다.

생성기 병합·공개 SDD 반영·Pages·공개 산출물의 실제 검증 기록은 배포 후 `release.json`과 연결합니다. 이 문서 자체를 준비한 사실만으로 배포나 사람 평가가 완료됐다고 간주하지 않습니다.
