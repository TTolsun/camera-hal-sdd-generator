# 사내 Camera HAL 반입 · 2026-11-20

이번 반입본으로 생성한 사이트에서는 전체 문서를 Markdown으로 내려받거나 브라우저에서 PDF로 저장할 수 있습니다. 기존 사이트를 기준으로 생성기 변경에 따라 다시 번역하거나 검토할 분량도 확인할 수 있습니다.

## 반입과 검증

1. [릴리스 첨부 파일](https://github.com/TTolsun/camera-hal-sdd-generator/releases/tag/inhouse-2026-11-20)에서 `camera-hal-sdd-inhouse-2026-11-20.zip`과 같은 이름의 `.sha256` 파일을 받으세요. ZIP의 SHA-256을 확인한 뒤 새 폴더에 압축을 풉니다.
2. 압축을 푼 생성기 루트에서 의존성 설치 전에 `python tools/verify_import.py`를 실행하세요. 출력의 `source_commit`을 첨부한 `release-validation.json`과 대조합니다.
3. 동봉한 `START_PROMPT.txt`에 사내 경로와 승인된 CLI 설정을 입력하세요. Hermes를 선택한 경우 `START_PROMPT_HERMES.txt`를 사용합니다. 기존 설정과 검토 기록은 보존하고 새 생성기와 스킬 경로를 함께 지정합니다.
