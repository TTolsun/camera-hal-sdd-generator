# 사내 반입 릴리스 · 2026-11-04

**사내에서 선택한 CLI로 시작할 수 있도록 스킬·반입 지침·설정 예시를 통일했습니다.** Hermes, OpenCode, Claude Code, Codex를 선택할 수 있으며 공개 기본 프로필을 사내 환경에 강제하지 않습니다. 이번 변경은 안내·설정 예시·회귀 시험에 한정됩니다. 실제 사내 HAL이나 새 모델 호출을 검증한 릴리스는 아닙니다.

## 이전 릴리스에서 달라진 점

이전 기준은 [inhouse-2026-11-03](https://github.com/TTolsun/camera-hal-sdd-generator/releases/tag/inhouse-2026-11-03)입니다. 이전 태그·ZIP·검증 기록은 보존합니다.

| 변경 | 사용자가 할 일 |
|---|---|
| CLI 선택을 공통 절차로 정리했습니다. | `agent.runner`에 `hermes`, `opencode`, `claude`, `codex` 중 승인된 실행기를 지정합니다. 이미 선택한 사내 실행기를 유지합니다. |
| 로컬 덮어쓰기 예시를 추가했습니다. | `examples/inhouse-template/sdd.cli.local.example.yaml`을 사내 설정의 `sdd.local.yaml`로 복사합니다. 기존 파일이 있으면 다른 설정을 보존하고 `agent`만 병합합니다. |
| 실행기 전환 시 모델·인자 상속을 명확히 했습니다. | `runner`와 함께 `command`·`model`·`args`를 교체합니다. 키를 생략하면 이전 값이 남습니다. `model: ""`, `args: []`, `command: []`로 이전 값을 제거할 수 있습니다. |
| 스킬의 직접 API 시험 지시를 수정했습니다. | 실제 재현 시험은 선택한 CLI로 수행합니다. 직접 HTTP 비교 시험은 별도 요청과 설정이 있을 때만 실행합니다. |
| 생성·번역과 별도 검토 설정을 구분했습니다. | 사내에서 승인한 검토 설정을 별도 실행하며 공개 프로젝트의 Codex 검토 정책을 사내 필수 조건으로 해석하지 않습니다. 자동 검토는 사람 승인이 아닙니다. |
| 배포 안내와 시작 프롬프트를 맞췄습니다. | 이 릴리스의 ZIP·시작 프롬프트·노트를 함께 사용합니다. 과거 설명을 시작 프롬프트로 덮어쓰는 방식 대신 스킬과 연결 가이드를 함께 갱신했습니다. |

공개 `examples/libcamera/sdd.yaml`과 사내 기본 템플릿의 Codex/Terra High 값, CLI 사용법과 `impact.json` schema 1은 유지합니다. 사내 선택은 로컬 덮어쓰기 또는 별도 전체 설정으로 적용합니다. 실행기·모델을 바꿀 때 기존 영수증을 새 호출 기록으로 바꾸지 않으며 현재 입력·정책·실행 설정에 맞는 결과만 재사용합니다.

Hermes 예시는 모델을 Qwen에 고정하지 않습니다. 제공자·인증·모델은 승인된 Hermes 환경에서 설정하거나 실행별 인자로 지정합니다. Codex는 격리 실행에서 사용자 설정 파일을 읽지 않으므로 모델·추론 강도를 실행별로 명시합니다. 세부 동작은 [CLI 선택 안내](cli-agents.md)가 기준입니다.

## 반입과 실행

[릴리스 페이지](https://github.com/TTolsun/camera-hal-sdd-generator/releases/tag/inhouse-2026-11-04)에서 다음 파일을 함께 받으세요.

| 첨부 파일 | 용도 |
|---|---|
| `camera-hal-sdd-inhouse-2026-11-04.zip` | 같은 커밋의 생성기·가이드·스킬·템플릿·시험입니다. |
| `camera-hal-sdd-inhouse-2026-11-04.zip.sha256` | ZIP의 체크섬입니다. |
| `START_PROMPT.txt` | CLI 선택·사내 경로·허용 범위를 채워 전달하는 프롬프트입니다. [시작 프롬프트](package.md#시작-프롬프트)와 같은 커밋에서 가져옵니다. |
| `RELEASE_NOTES.md` | 이 릴리스 노트의 사본입니다. |
| `release-validation.json` | 정확한 기준 SHA, 테스트·CI·패키지 검증과 공개 사이트 확인 결과입니다. |
| `SHA256SUMS.txt` | 나머지 첨부 파일의 SHA-256 목록입니다. |

1. GitHub의 자동 Source code ZIP 대신 위 반입 ZIP과 체크섬을 받습니다. 새 폴더에 풀고 설치·수정 전에 `python tools/verify_import.py`를 실행해 `source_commit`과 `verified_files`를 기록합니다.
2. Python 3.11 이상과 대상 OS·CPU에 맞는 의존성·제품 툴체인·승인된 Mermaid 자산을 준비합니다. ZIP은 wheel·모델·CLI 인증을 포함하지 않습니다. Windows에서는 짧은 경로와 긴 경로를 지원하는 압축 도구를 사용합니다.
3. 템플릿을 사내 설정 저장소로 복사하고 CLI·모델·실제 제품 경로를 설정합니다. Hermes를 선택했다면 동봉 로컬 예시를 적용하고 승인된 Hermes 환경을 사용합니다.
4. 시작 프롬프트를 전달하고 [반입 안내](package.md)의 추출·계약 작성·생성·검사·사이트·실패 복구 절차를 수행합니다. `doctor`의 설치 확인과 실제 모델 호출 성공을 구분합니다.

선택한 CLI가 없거나 실패하면 원인과 미완료 단계를 남깁니다. 다른 CLI·직접 API·저장 응답·수동 원고로 대체해 성공으로 보고하지 않습니다. 소스·파생 설정·facts·원고·프롬프트·로그는 사내에 보관합니다.

## 업그레이드와 검증 범위

기존 설정·원고·facts·호출 기록·상태·승인 장부·정상 사이트를 함께 보존하고 새 반입본은 별도 폴더에서 확인합니다. 설치된 스킬만 새 버전으로 바꾸지 않습니다. 복구 시에도 같은 버전의 생성기·설정·산출물·상태를 함께 사용합니다.

검증 결과는 첨부 `release-validation.json`에서 확인합니다. CLI 선택 회귀 시험은 네 실행기에 공통 예시를 적용했을 때 이전 모델·인자·실행 경로가 제거되고 다른 프로젝트 설정은 유지되는지 확인합니다. CLI 응답·실패 시험은 테스트 대역을 사용하며 실제 모델 호출 성공을 뜻하지 않습니다. 패키지는 같은 커밋의 재현 빌드·체크섬·압축 해제 후 무결성·동봉 CLI 실행을 확인합니다.

공개 문서 생성 코드·입력·원고·집필 규칙·사이트 자산은 이번 변경 대상이 아니므로 빈 SDD 배포 커밋을 만들지 않습니다. 기존 Pages 상태와 공개 산출물 확인은 검증 기록에 따로 남기며 upstream의 최신 커밋과 문서 분석 기준을 혼동하지 않습니다. 이번 안내 갱신은 전체 문서 재생성이나 [시각화 전체 보완 #215](https://github.com/TTolsun/camera-hal-sdd-generator/issues/215)의 완료가 아닙니다.

실제 사내 HAL 추출·승인된 CLI의 새 호출·문서 의미 검토·독립 독자 평가·실기기 시험·사내 게시·사람 승인은 실제 환경에서 수행할 별도 단계입니다.
