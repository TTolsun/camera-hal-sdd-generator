# #107 후속 평가: 공개 libcamera와 사내 적용 판단

이 기록은 2026-10-27 착수 Goal의 후속 평가입니다. 이전 [평가 기록](reader-evaluation-107.md)의 예외·부분 반영·측정값은 당시 기록으로 보존합니다. 이번 실행은 사용자가 선택한 Claude CLI `claude-haiku-5-5 --effort high`를 사용합니다. 공개 libcamera 시험이며 사람 승인이나 사내 HAL 검증이 아닙니다.

## 기존 구현과 이번 작업의 구분

A1~A4의 중복·질문 누출·이동 안내·slug 처리는 기존 #111, A5/A6 문단 묶기는 #118에서 구현됐습니다. A7의 짧은 상태 표시는 착수 전에 있었습니다. B1의 비코드 근거, B2/B3의 Vendor 질문과 계층 그림, B4의 타팀 입구, B5의 온보딩 경로도 기존 구현입니다. 비교 제품의 정량 성능이나 사내 조직 역할을 만들지 않는 B6 경계는 계속 유지합니다.

이번 변경은 기존 중복 검사의 서로 다른 함수·필드 오탐과 기반 클래스 주체 오인을 바로잡고, 실제 중복을 만들던 질문을 합치며 모든 고유 조건·책임을 보존합니다. CLI의 native schema·영수증·검증 항목 보존·현재 정책 재검토와 관련 한영 계약 대조를 추가합니다. 이전 response-bundle 예외를 이번 신규 생성에 적용하지 않습니다.

## 비교 페이지와 브라우저 준비 결과

대상은 동일한 여섯 경로입니다: index, vendor-overview, vendor-assurance, overview, vendor-integration, scenarios/queue_request. 착수 기준 브라우저 자료와 직전 공개판 확인을 별도 보존합니다. 직전 공개판은 다른 세션의 PR #49를 포함하므로 착수판과 동일하다고 취급하지 않습니다.

2026-10-28 배포 전 격리된 headless Chrome 155.0.8059.85에서 여섯 경로가 모두 HTTP 200이었습니다. 데스크톱 여섯 페이지와 모바일 세 페이지에 가로 넘침·페이지 JavaScript 오류가 없었습니다. 검색 결과 19개, Escape 닫기, 근거 접기, 그림 검색 2개 일치, 확대 125%, 그림 Escape 닫기를 확인했습니다. 이 결과는 새 후보를 배포했다는 증거가 아닙니다. 최종 후보와 공개 URL 확인은 아직 남아 있습니다.
