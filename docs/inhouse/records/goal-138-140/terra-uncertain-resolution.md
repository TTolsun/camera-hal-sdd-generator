# 실제 한영 감사 미판정 90건의 원인 조사

미판정 수 자체는 기존 게시 계약의 차단 조건이 아니다. 확정 모순, 현재 입력·정책·영수증 불일치는 게시를 차단하며 미판정과 `human_review: pending`은 보존한다. 그러나 이번 90건을 모두 무해한 것으로 취급하지 않는다. 원래 보고서·28원고·영문 카탈로그·facts·질문을 `uncertain90-before`에 복사해 보존하고 각 판정의 원문·이유·직접 근거·누락 근거를 기록했다.

구조적 1차 분류는 직접 근거 공급 누락 73건, 추가 범위 검토 15건, 실제 부정 조건 누락 2건이다. 이는 판정 변경이나 최종 해소 수치가 아니다. 추가 15건 중 12건은 표시 문단에 합쳐진 다른 설명의 직접 근거를 감사가 전달하지 않았고, 나머지 3건은 시나리오의 분석 표기·한계를 설명하는 동일 문단과 한영 표시다. 실제 미판정 이유와 근거를 대조해 후속 감사를 진행한다.

`consistency.request()`는 직접 근거를 모은 뒤 계약별 선택 목록이 있으면 이를 빈 사전으로 대체했다. 선택 근거를 직접 근거에 추가하도록 고치고, 실제 한영 표시 문단에는 합쳐진 모든 설명의 직접 근거를 연결한다. 시나리오의 기존 코드 인용도 같은 소스·파일·줄을 포함하는 검증된 문맥과 연결한다. 동일한 커밋·파일·줄·원문·해시의 발췌만 공유하고 별칭은 보고서에 남긴다.

배치마다 대상 설명과 모든 주 문서 설명·직접 근거, 선택된 공통 근거를 유지한다. 실제 CLI 프롬프트에는 전체 원문·위치·주장·근거 관계를 그대로 전달한다. 선택 정규식이나 이미 로컬에서 대조한 해시 같은 비의미 메타데이터는 바인딩된 보고서에 보존한다. schema까지 포함한 실제 프롬프트 길이로 배치를 분할하며, 한 대상과 완전한 주 문맥도 40,000자에 들어가지 않으면 실패한다. 원문이나 주장을 잘라 통과시키지 않는다. 현재 후보 입력 사전 검사는 303주장·76배치, 각 그룹 최대 39,989/39,792/37,404/39,744자였다. 후속 원고 수정에 따라 실제 배치 수를 다시 측정한다.

두 모호 판정은 `request-diagnosis/diagnosis/pending-head`의 같은 한영 설명에서 `ASSERT(!req->hasPendingBuffers())`의 부정을 생략한 실제 문제다. 정확한 단언 식과 검사 조건을 묻고 원문의 코드 조건을 필수 용어로 두어, 선택된 Terra High CLI로 재생성·재번역한다. 원고·HTML을 직접 수정하거나 판정 상태를 수동으로 바꾸지 않는다.

호출 집계에서도 설계 생성 691회 외에 리뷰어용 `change_impact` 호출 1회가 있었다. 이 호출은 생성 예산과 원고 보존 경계 뒤에서 실행되므로, 변경 영향 요약을 기존 `impact.json`·facts의 결정적 사실 요약으로 구성하도록 수정했다. CLI·schema 1을 유지하고 불필요한 보조 LLM 호출을 제거한다. 완전 캐시 재개가 추가 모델 호출 없이 같은 비교 SHA·영향 섹션을 보고하는 실제 CLI 회귀와 기존 예산 소진 회귀 2개가 통과했다. 과거 실제 1회는 삭제하거나 전송 확인 호출로 재분류하지 않는다.

독립 감사 #155의 후보와 당시 main 간 두 정책 차이는 통합 브랜치의 같은 Python 실행기에서 재대조했을 때 0이었다. #156의 Python AST 표현 차이도 별도 환경 차이로 기록하고, 정책 해시를 고정하거나 검사를 생략하지 않는다. 최종 main·Python 버전·정책 지문으로 게시 관문을 다시 확인한다. 모든 결과는 자동 검증이며 사람 승인이나 사내 HAL 검증이 아니다.

실제 부정 조건은 같은 Terra High CLI의 전체 재개에서 **19/19 통과·2개 새 호출·45.484초**, **306개 원고 재사용·7개 체크포인트 재사용·1개 신규 단위**로 반영됐다. 영문은 달라진 1문자열만 같은 CLI로 번역했고 전체 카탈로그는 30쪽·1733문자열이다. 코드 식별자를 지운 한글 부분 일치 대신 동일 렌더러가 만든 실제 전체 표시 문장으로 합쳐진 문단의 근거를 연결한다.

시나리오 표기 3건은 제품 실행 보장과 다른 분석 표현의 계약이다. 추출된 시나리오 지문을 확인하고 실제 Message/Scenario 정의·예약 대상 추출·가상 후보 탐색 코드·렌더러의 표현 계약을 별도 `analysis-definition` 근거로 제공한다. 이는 제품 실행·콜백 스레드·소유권·장치 성능을 입증하는 근거로 사용할 수 없도록 명시한다. 임의 제품 문장이나 변조된 시나리오에는 이 근거를 붙이지 않는다.

완전한 주 문서·필요 원문을 4만 자에 유지하기 위해 제품 콜백 계약과 분석 표현 계약을 분리한다. 기존 콜백 87개 주장 ID가 두 관련 범위에 모두 남아 있음을 대조했고, 제품 문서들은 분석 계약에서도 교차 대조한다. 주장을 없애거나 원문을 줄이지 않는다. 현재 입력 사전 검사는 **387판정·85배치**, 그룹별 최대 **39,652/39,155/36,527/39,845/39,451자**이다. 선택 설정·로컬 검증 해시·표시 기원 ID 같은 중복된 비의미 메타데이터는 원래 보고서에 보존하고, 모델에는 모든 원문·위치·주장·언어·번역 관계·직접 근거·주 문서 문맥을 전달한다. 한 대상도 완전하게 들어가지 않으면 여전히 실패한다. 실제 재감사와 원래 90건별 해소 상태는 별도로 기록한다.

공개 GitHub blob과 대조한 세 감사 모듈을 같은 Terra High CLI로 코드 검토해 세 지적을 반영했다. 제품 계약은 분석 정의만 인용해 확정할 수 없고, 분석 표현은 자신의 분석 정의 없이 확정할 수 없도록 결정적으로 검사한다. 짧은 표시 문장도 문장 경계와 실제 코드 식별자를 유지해 포함하며, 인용 줄 밖의 unavailable 근거 때문에 유효한 인용을 막지 않는다. **관련 회귀 29 passed**를 확인했다.

첫 확장 실제 CLI 사례 시험은 **26/27**, 오탐 **1건**이었다. 미확인 외부 호출을 소스의 알려진 함수와 다르다는 이유만으로 모순으로 분류한 결과를 원본과 함께 보존했다. 같은 함수 호출의 명시적 잘못된 수신자·동작과, 소스가 설명하지 않는 외부 행위자를 구분하는 정책을 보완하고 전체 사례를 다시 실행한다. 기대 판정이나 원래 실패 결과는 수정하지 않는다. 보완한 현재 입력 사전 검사는 **387판정·86배치**, 실제 최대 **39,914/39,417/36,789/39,924/39,845자**다.

최종 고정 사례 재실행은 **21사례·27주장 모두 예상 판정과 일치**했다. 중요 모순 10/10, 누락 0, 오탐 0, 정상 13, 예상 미판정 4다. 실제 21개 완료 영수증의 Codex/Terra 모델 선택과 `model_reasoning_effort="high"` 인자를 확인했다. CLI JSONL은 독립적인 백엔드 canonical model을 노출하지 않으므로 이를 추가로 입증했다고 쓰지 않는다. 원본 실패 26/27과 새 결과를 각각 보존했다.

완전한 근거를 공급한 v7 전체 감사는 86개 새 호출·387판정에서 모순 0, 미판정 4였다. 그중 3건은 같은 접근 의무 문단의 한영·계약별 판정이다. 취소 뒤 접근 금지를 파이프라인 핸들러보다 넓은 모든 호출자로 표현한 실제 범위 문제를 확인했다. 질문의 주체 범위를 명시한 첫 시도는 앞 문단과 중복되어 거부됐고, 검사 완화 없이 두 접근 질문을 하나의 비교 질문으로 합쳤다. 실제 v9 전체 생성은 **19/19·2새호출·49.688초**, 원고 단위 재사용 299·체크포인트 재사용 13·신규 1이었다. 변경 1문자열을 같은 CLI로 번역했다. 기존 실패와 원고를 보존했다.

최종 v9 전체 감사는 **386판정: compatible 385, 확정 모순 0, insufficient-evidence 1**이다. 작업자 실제 새 호출 74·검증된 재사용 13·벽시계 266.984초이며, 이후 정식 전체 CLI 감사는 새 호출 0·재사용 87이다. 공통 기준 문서의 변경은 관련 그룹 전체 검토에 전파하고, 입력이 일치한 분석 그룹의 13배치만 재사용했다. 원래 미판정 **90건 모두**를 원래 판정·원문·직접 근거·누락 근거와 최종 주장 ID·근거·이유에 대응시킨 [JSON 장부](terra-uncertain-90-resolution.json)를 남겼다. 실제 누락된 부정·행위자 범위는 원고 재생성으로 고쳤으며, 과거 문장 자체가 옳았다고 소급 판정하지 않는다. 합쳐진 접근 질문과 달라진 한영 카탈로그 ID의 계보를 명시했다.

새로 남은 1건은 `scenarios/queue_request.md`의 다음 문서 이동 링크다. C++ 함수 계약만으로 문서 존재·링크 연결을 입증할 수 없다는 미판정을 유지하고, 실제 사이트의 로컬 대상·앵커 검사와 브라우저 검증에 연결한다. 제품의 완료·취소·소유권 계약에 대한 미판정이나 확정 모순과 혼동하지 않는다. 최종 감사·CLI 회귀는 **51 passed**다. 앞선 샌드박스 Temp 번호 디렉터리 생성 오류 31건은 assertion 실패가 아니었으며, 작업 트리의 새 전용 임시 경로로 재실행했다. `human_review: pending`과 원래 실패 기록을 유지한다. 공개 배포 확인은 후속 단계다.
