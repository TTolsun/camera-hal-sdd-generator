이 기록은 공개 libcamera만 사용합니다. 사내 HAL의 제품 제공·측정 결과나 #163의 실제 독자 시험을 완료한 기록이 아닙니다. 생성기 #169·#173과 반복 안정성 후속 #177은 병합됐으며 source212의 최종 공개 배포는 별도로 확인합니다. #177의 필수 CI 네 환경 실행은 `40935265084`, 병합 커밋은 `628667f763b35855eb9422f13e5d86abce7af64f`입니다.

## 같은 e117 소스의 세 독자 문서

[비교 보고서](reader-scope-same-e117.json)는 완성된 기존 공개 원고와, 같은 e117 facts에서 새 범위 계약으로 작성한 세 문서를 비교합니다. 근거 수집을 제외한 구조 facts가 같은지도 대조했습니다. 제품 입력은 이 시험에서 제외했으며 #165의 가상 두 구성과 실제 source212 통합은 별도 증거입니다. 독자 과업은 신규 출력 전에 고정한 계약을 그대로 사용합니다. e117 비교를 선택한 시점은 앞선 source212 이전 계약 시험의 실패 이후임을 보고서에 명시했습니다.

| 독자 문서 | 이전 설명 글자 | 이후 설명 글자 | 이후 필수 질문 누락 |
|---|---:|---:|---:|
| 고객사 개요 | 2669 | 2562 | 0 |
| 신입용 개요 | 2293 | 2129 | 0 |
| 타팀 개요 | 2145 | 2265 | 0 |

글자 수는 검증된 설명 문장만 세며 발췌·그림·메타데이터는 제외합니다. 짧아진 정도를 품질 점수로 쓰지 않습니다. 타팀 설명은 늘었습니다. 보고서는 과업별 질문·답변 위치·미해결 항목과 선택 상세·제외 사유를 함께 보존합니다. 두 개요의 요청 한도 설명은 기존 `pipeline-requests.md` 상세로 옮기는 계약이며, 이 부분 시험에는 해당 상세를 새로 생성하지 않았습니다. 실제 상세 본문과 링크는 source212 공개 통합 결과에서 따로 확인해야 합니다. 이동 대상 외의 소스 해시는 유지됐습니다.

세 문서의 실제 독립 Codex CLI/Terra/high 생성·근거 대조는 94회 호출이었고 응답 검사를 모두 통과했습니다. 다만 세 페이지만 있는 시험 작업공간은 다른 설정 페이지가 없어 전체 문서 수명주기 검사 46건에서 반려됐습니다. 이 종료 결과를 전체 CLI·게시 성공으로 바꾸지 않습니다.

앞선 source212의 이전 계약 시험은 95회 호출 후 고객사 문장 반복으로 반려됐고, 나머지 두 문서의 응답 검사는 통과했습니다. 두 문서를 재검증한 실행은 신규 호출 0회였지만 같은 부분 작업공간의 전체 수명주기 검사는 47건에서 반려됐습니다. 실패 결과와 비용은 그대로 보존합니다.

첫 e117 반복 실행은 호출 0회에도 실행 메타데이터를 다시 써 원고 해시가 바뀌는 결함을 드러냈습니다. [수정 후 반복 증거](scope-repeat-proof.json)에서는 #177의 `b0f80f3`로 같은 세 문서의 전체 바이트가 유지됐고 신규 호출은 0회였습니다. 두 반복 실행은 모두 부분 작업공간의 전체 수명주기 검사에서 반려됐으며, 이 관문을 끄지 않았습니다. 입력·정책·본문·검토 상태나 원래 영수증 연결이 바뀐 경우는 보존하지 않는 회귀도 추가했습니다.

원본 `run.json`의 `source_commit` 필드는 소스 작업 디렉터리의 당시 HEAD인 212를 기록합니다. e117 시험의 실제 분석 기준은 `facts.json.meta.source_commit`과 원고의 e117이며, 발췌도 `git show e117:...`로 수집해 검증했습니다. 작업 디렉터리 HEAD와 고정 분석 기준을 혼동하지 않습니다. 과거 실행 기록은 수정하지 않았습니다.

## 원본 보존

[원본 ZIP](reader-cli-comparisons.zip)과 [파일별 해시](archive-index.json)에 5개 실행, 실제 요청·응답·CLI 영수증·native 출력, 입력 facts·설정·생성 원고·현재 체크포인트·실행 보고서를 보존했습니다. 1,659개 파일, 원본 29,680,424바이트이며 ZIP의 각 파일을 다시 읽어 SHA-256을 대조했습니다. 원고·응답을 수동으로 고치거나 저장 응답을 새 모델 호출로 보고하지 않습니다.

## 공개 #57의 화면과 산출물

공개 PR [#57](https://github.com/TTolsun/libcamera-sdd/pull/57)은 `4796de239971223fd664f5efc5821d4053c5042c`로 병합됐고 [Pages 실행](https://github.com/TTolsun/libcamera-sdd/actions/runs/40928172429)은 성공했습니다. 분석 기준은 e117이며 새 원고 호출은 없습니다. build_id는 `b409cfc4cbb03e6db8e9397b520089f3a2be84659a85ef33559680ce3b697c3d`입니다.

[독립 HTTP 대조](public166-http.json)는 HTML 60쪽과 모든 manifest CSS·JavaScript의 실제 공개 바이트를 검사했습니다. 다른 산출물은 이 독립 확인의 범위 밖입니다. [전후 보존 대조](public166-preservation.json)는 60쪽의 기존 소스 목적지·발췌 앵커·코드 블록 해시와 문단 대응 386개를 확인했습니다. 문단 조작 행은 0개입니다.

실제 공개 대표 한영 10쪽을 [1440px](browser/public-desktop.json)와 [390px](browser/public-mobile.json)에서 확인했습니다. 개요·연동·개발자·시나리오의 문단 행과 가로 넘침은 없었습니다. [검색·확대·키보드 기록](browser/public-controls.json)과 [데스크톱 화면](browser/public-reading-flow.jpg), [모바일 화면](browser/public-mobile-ko.jpg)을 함께 남깁니다. 이는 사용자 내용 평가 점수가 아닙니다.

JavaScript 없는 시험은 동일한 생성 HTML에 [HTTP sandbox 정책](browser/scriptless-http.json)을 적용해 수행했습니다. `allow-scripts`가 없는 sandbox와 `script-src 'none'`으로 문서 스크립팅을 금지했습니다. [한국어](browser/no-script-source.json)와 [영어](browser/no-script-en.json)의 절·발췌를 키보드로 펼쳐 원문과 해시를 읽었습니다. Chrome 전역 설정을 바꾼 시험으로 표현하지 않습니다.

실제 Chrome 인쇄 미리보기는 도구의 URL 확인 제약으로 직접 조작하지 못했습니다. 사용자가 한영 페이지 각각에서 Ctrl+P를 열어 문단 행 부재와 절 근거 유지 두 조건을 확인했습니다. [사용자 확인 기록](browser/print-user-confirmation.json)은 그 범위를 명시하며, 에이전트 직접 검사나 #163의 내용 독자 평가로 바꾸지 않습니다.

공개 #57의 한영 첫 안내에는 아직 이전 문단 근거 사용법이 남아 있습니다. 생성기 예제는 수정됐지만 source212 최종 공개 갱신에서 안내·번역을 확인해야 합니다. 이 기록만으로 #164·#165·#166을 닫거나 Goal을 완료하지 않습니다.
