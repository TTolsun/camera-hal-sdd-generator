# 저장소 작업과 함께 공개 libcamera 문서 갱신하기

**이 저장소에서 작업할 때 upstream 동기화와 공개 문서 보완·배포를 함께 수행합니다.** 공개 환경에는 매일 21시 등의 정기 예약을 설치하지 않습니다. 정기 실행과 시간 변경은 사내 환경을 위한 [공통 실행기 기능](scheduled-publication.md)으로 유지합니다.

1. 공식 libcamera master와 공개 `upstream/master`를 비교하고 새 이력을 fast-forward로 동기화합니다.
2. 새 커밋이 있으면 변경 범위에 맞게 빌드·추출·원고를 갱신합니다. 새 커밋이 없으면 기존 카테고리의 누락을 찾아 보완합니다.
3. 근거·원고·사이트를 검증하고 문서 PR을 생성·병합합니다. 자동 검사와 에이전트의 소스 대조를 사람 승인으로 표시하지 않습니다.
4. GitHub Pages 배포 성공과 실제 URL의 manifest·전체 산출물 해시를 확인합니다.

단순 재빌드나 소스 창 하나의 no-gap 응답만으로 누락 보완을 끝내지 않습니다. 유효한 근거를 찾지 못한 제안은 보류하고, 확인한 범위와 남은 항목을 구분해 보고합니다. 변경할 내용을 억지로 만들어 게시하지 않습니다.

공개 저장소의 `sync-upstream.yml`은 필요한 경우 수동 실행할 수 있습니다. 이력 동기화만 수행하므로 문서 생성·배포 완료를 대신하지 않습니다.

로컬 실행 설정·facts·원고·상태·감사 기록은 환경별 운영 데이터입니다. 사내 입력에서 파생된 기록은 공개 libcamera 저장소에 게시하지 않습니다.
