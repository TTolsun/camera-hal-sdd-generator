In the enlarged diagram, dragging with the primary mouse button scrolls the drawing without changing the zoom level. Links, buttons, form fields, the toolbar, and scrollbars are excluded from dragging, so they keep their existing behavior. Pointer capture is released, and the drag state is cleared, when the button is released, when the pointer is cancelled or loses capture, when the dialog closes, when the window loses focus, or when the window resizes. For touch, no custom touch-event handling is added, so the browser's native horizontal and vertical scrolling, inertia, and pinch zoom remain in use.
