다이어그램 대화상자는 열릴 때 배율을 자동으로 정하며, 데스크톱과 모바일에서 가장 작은 글자가 본문 글꼴 크기와 같아지는 것을 목표로 합니다. 측정은 SVG를 대화상자 안으로 옮긴 뒤 100% 배율에서 수행하며, 노드와 간선의 글자와 foreignObject 안의 HTML 글자를 모두 포함합니다. 각 글자 크기에 화면 변환 배율을 곱해 실제 화면 기준 크기로 환산합니다. 여기서 100%는 SVG 원본 좌표 크기를 뜻하며, 원본 크기를 알 수 없을 때만 화면에 그려진 크기를 기준으로 합니다. 본문 글꼴 크기를 읽을 수 없으면 16px를 기준으로 하고, 측정할 글자가 하나도 없으면 100%로 엽니다. 초기 배율은 100% 아래로 내려가지 않고 800%를 넘지 않으므로, 글자가 이미 충분히 크면 원래 크기로 열리고 글자가 아주 작은 그림은 800%에서 멈춰 본문 크기에 닿지 못할 수 있습니다. '화면에 맞춤' 버튼을 명시적으로 누를 때만 뷰포트에 맞춘 전체 보기가 적용되며, 이때도 배율은 100%를 넘지 않습니다. 창 크기가 바뀌면 화면 맞춤 모드에서만 다시 맞추고, 읽기 모드와 수동 배율은 그대로 둡니다. 노드 검색은 배율을 바꾸지 않고 일치 항목을 강조하며 첫 항목으로 스크롤하고, 대화상자를 닫으면 SVG를 원래 위치와 원래 스타일로 되돌리고 열었던 요소에 포커스를 돌려주며 수동 배율은 5%에서 800% 사이로 제한됩니다.

The diagram dialog chooses its opening scale automatically so that the smallest label aims to match the body font size on both desktop and mobile. Measurement runs after the SVG is moved into the dialog, at 100% scale, and includes node and edge labels as well as HTML labels inside foreignObject; each label size is multiplied by its on-screen transform scale. Here 100% means the SVG's original coordinate size, and the rendered size is used only when that original size is unavailable; it is not the size the page's CSS sets. If the body font size cannot be read, 16px is the reference, and if no label can be measured, the dialog opens at 100%. The initial scale never drops below 100% and never exceeds 800%, so a diagram whose labels are already large opens at its intrinsic size, while a diagram with very small labels may stop at 800% and not reach the body font size. Only an explicit click on the 'Fit to screen' button applies the overview that fits the viewport, and even then the scale does not exceed 100%. A window resize refits only in Fit mode and leaves reading and manual zoom unchanged. Node search does not change the scale; it highlights matches and scrolls to the first one, and closing the dialog restores the SVG to its original DOM position and style, returns focus to the element that opened it, and limits manual zoom to 5% through 800%.
