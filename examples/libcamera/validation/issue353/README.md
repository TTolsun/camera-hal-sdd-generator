# 공개 libcamera 독자용 축약판 검증

원고의 출발점은 공개 Pages 커밋 `3d0fabe78a8b8424d29d8cdbafdb0a36fd570624`, 빌드 `487c721820c766ec6e3985022955f057b5a7d718fdc9a37c0f1c265a94bf515e`, libcamera 커밋 `adfa719f8ed67d18fd8a0739fc088a1f8b9e7252`입니다. [독자용 설정](../../config/reader-edition.yaml)의 `sections`와 `aliases`는 이 기준의 한영 절 앵커와 옛 주소를 가리킵니다. 전체 원고에서 독자가 먼저 볼 절을 선별하며, 장치별 상세 조건과 근거는 기존 호환 주소에서 열 수 있습니다.

## 변경을 반영할 범위

| 달라진 사실 | 갱신 위치 |
|---|---|
| 함수 이동으로 설명과 그림을 유지할 수 있습니다. | 바뀐 발췌와 코드 위치만 다시 검증합니다. 기존 답변의 입력과 일치하면 본문을 이월합니다. |
| 프로젝트 역할, 공통 API, 장치 책임이 달라집니다. | 시작하기와 ForVendor의 해당 설명을 갱신합니다. 경계가 달라지면 Architecture도 대조합니다. |
| 플랫폼, 빌드 선택, 구성 조건 또는 확인된 지원 범위가 달라집니다. | 기능·지원 범위의 원고와 대응하는 지원표 행을 갱신합니다. 도입 판단이나 절차까지 바뀌면 ForVendor와 장치 연동과 검증도 대조합니다. |
| 첫 실행의 명령, 성공 조건, 코드 진입점이 달라집니다. | ForDeveloper의 해당 절을 갱신합니다. |
| 공통 요청·버퍼 수명 또는 완료·정지 계약이 바뀝니다. | 요청 흐름과 핵심 개념의 해당 답과 그림을 갱신하고, 진단과 대상 보드 확인 항목을 대조합니다. |
| 장치별 구현, 확장 또는 실패 조건이 바뀝니다. | 구현·확장 지점 또는 주의점과 문제 진단의 해당 사례를 갱신합니다. |
| 용어가 새로 생기거나 정의가 달라집니다. | 용어집과 그 정의를 실제로 사용하는 절을 대조합니다. |

생성·번역과 독립 근거 대조에는 공개 예제의 지정 Codex CLI 프로필을 사용합니다. 소스 근거가 부족하면 검토할 범위와 불확실한 답을 기록합니다. 동일한 답을 기존 절에서 제공할 수 있다면 그 절을 갱신합니다. 검증과 번역을 마친 원고에서 사이트를 다시 구성하고 링크를 확인합니다.

## 실제 이력 세 가지 대조

| 소스 변경 | 새 페이지에서 달라지는 범위 |
|---|---|
| `16a469a1…b6f81b75`에서 `hasPendingBuffers()` 정의가 이동했습니다. | 요청 흐름과 핵심 개념의 `stop-and-disconnect`와 장치 연동과 검증의 `stop-tests`는 인용 위치만 바뀌었습니다. 비교한 네 답변과 그림의 내용은 유지됐습니다. |
| `0d48cb6b…0b0f32e7`에서 RKISP1의 보정 경로를 수정했습니다. | 구현·확장 지점의 `rkisp1-dewarp`에 매핑되는 `application`만 바뀌었습니다. 비교한 두 공통 정지 절의 답변·인용·그림은 유지됐습니다. |
| `517b863b…731a340c`에서 공통 정지 시 대기 요청의 완료 경로를 수정했습니다. | 요청 흐름과 핵심 개념의 `stopping` 답변과 그림, 장치 연동과 검증의 `shutdown` 답변이 바뀌었습니다. 취소 상태 접근자와 프레임 상태 설명은 유지됐습니다. |

[이전 실행의 재현 절차](../issue348/README.md)에 따라 실제 커밋의 부모·head facts를 준비하고 초기 head와 같은 입력의 재실행 원고를 보존합니다. 검증 스크립트는 각 스냅샷의 소스 커밋, 네트워크 호출 기록이 아닌 CLI 호출 시도 횟수, 답변, Mermaid, 인용 및 동일 head의 본문 해시를 읽어 새 페이지·절에 대응시킵니다. 한 번 더 생성한 원고에서 세 사례 모두 CLI 호출이 0회였고 본문이 같았습니다.

```powershell
uv run python examples/libcamera/validation/issue353/verify_incremental_routes.py <issue348-run>
```

이 대조에서는 #348에서 만든 범위 제한 Markdown 스냅샷과 CLI 장부를 읽었습니다. 현재 사이트 전체에 과거 커밋을 섞지 않습니다. 현재 공개 사이트 링크, 기기 관측, 사람 승인과 사내 적용은 별도로 확인합니다.
