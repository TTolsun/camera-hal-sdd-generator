# 독자 과업 보완의 브라우저 회귀 검사

`browser_test.cjs`는 공개 libcamera 예제의 새 그림 3개와 진단 절에서 이어지는 연결 3개를 한국어·영어, 1280px·390px의 새 Chrome 컨텍스트에서 검사한다. 사람 읽기 부담, 실제 독자 수행과 물리 장치 시험은 측정하지 않는다.

실행 환경에 Node.js, Chrome과 `playwright` 패키지를 준비한다. 프로젝트 전역 의존성에 추가할 필요는 없다. 이미 실행한 loopback 정적 미리보기의 URL, 새 결과 디렉터리와 **그 서버가 제공해야 하는 실제 사이트 디렉터리**를 함께 전달한다.

```text
node browser_test.cjs http://127.0.0.1:PORT/ NEW_RESULT_DIRECTORY EXACT_SITE_DIRECTORY
```

Node의 패키지 검색 경로에는 설치한 Playwright를 연결해야 한다. 결과 디렉터리가 이미 있으면 덮어쓰지 않는다. 검사 전에는 선택한 한영 HTML 6개와 공통 CSS·JavaScript의 HTTP 응답을 실제 디렉터리의 SHA-256과 대조한다. 다른 작업이 같은 포트를 쓰면 서버 응답 불일치로 실패해야 한다.

검사는 그림의 실제 노드 수, 확대·전체 보기·검색·Esc 종료와 초점 복원, 수평 문서 넘침, 세 연결의 언어 경로·H2 도착 위치를 확인하고 PNG와 `report.json`을 남긴다. Mermaid가 모두 그려진 뒤에도 요청한 제목이 화면 밖에 있으면 실패한다. 전체 보기는 작은 글자를 포함할 수 있어 확대가 필요하다. 이 검사와 화면 확인을 실제 사람의 읽기 부담 점수로 바꾸지 않는다.

실패·재시도와 입력 버전은 [실행 기록](../../../../../docs/libcamera/records/issue253/reader-improvement-result.md)에 연결한다. 최종 발행 검사와 독자 재평가 전에 사이트의 소스·생성기·manifest·허용 파일 해시를 별도로 고정해야 한다. 이 검사 통과만으로 #163·#253, 전 문서의 항목별 그림 보완이나 사내 HAL 검증을 완료 처리하지 않는다.
