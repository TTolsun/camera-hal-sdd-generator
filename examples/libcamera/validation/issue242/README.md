# #242 후속 표본의 약어와 근거를 확인하세요

`glossary.yaml`은 #242의 공개 CLI 검증 표본에서 빠졌던 API와 LLM의 뜻을 제공합니다. 표본 설정의 `paths.glossary_file`에 이 파일의 절대 경로나 설정 파일 기준 상대 경로를 지정하고 `site.undefined_terms: fail`을 유지합니다. `common` 예외나 경고 끄기로 통과시키지 않습니다. 기존 API 답변은 다시 작성하지 않습니다.

```yaml
paths:
  glossary_file: glossary.yaml
site:
  undefined_terms: fail
```

위 상대 경로는 설정 파일과 용어집을 같은 디렉터리에 둔 경우입니다. 다른 디렉터리의 보관 표본을 복사했다면 실제 위치로 연결하고 경로 변경을 새 실행 기록에 남기세요. 오래된 원본 설정·보고서·영수증은 수정하지 않습니다.

2026-11-05 후속 조사에서 이전 미판정 두 건을 최신 공개 본문·소스와 다시 대조했습니다. 영어 문장의 잘못된 스트림 연결 표현은 #248에서 이미 재번역됐으므로 유지합니다. 큐의 오류 우선순위는 `include/libcamera/internal/camera.h:59–60`의 `allowDisconnected = false` 선언, 구현과 호출부를 함께 확인합니다. 전체 대조 보고서에서 이 선언이 빠졌던 사실을 지우지 않고 새 별도 검토에 정확한 원문·해시·줄을 제공합니다. 선언문은 공개 분석 커밋 `293d751a814e0d4c34e85ad457ccd9d5eefd1a61`에 고정합니다.
